問題

只會聊天的 LLM，哪裡不夠？

大模型很會做新任務，卻在算術、查事實這類基本功能上表現差 1。

  • 不會精確計算、不知道現在是什麼時間 2
  • 拿不到最新資訊，而且容易幻覺（hallucination）2
  • ReAct 的作者把只靠內部知識推理的做法（例如 CoT）形容成「靜態黑盒子」：不接觸外部世界，錯誤會沿著推理累積 3
💡 後面的 ReAct 要補的正是這種能力：去外部取得資訊、觀察結果，再回饋給下一步 4。

概念

Agent 的定義與四塊積木

Agent 是位於環境之中、感知環境並對其行動的系統，長期追求自己的目標 1。

  • Profile：決定 agent 的角色
  • Memory：記住過去的行為與觀察
  • Planning：把複雜任務拆成子任務
  • Action：把決策轉成具體輸出 2
💡 Profile 影響 Memory 和 Planning，三者一起影響 Action 2。

例子 · Wei et al. 2022

第一步：先想再答（Chain-of-Thought）

在 prompt 的範例裡寫出一步一步的推理過程，模型就會跟著先推理再回答 1。

A: Roger started with 5 balls.
   2 cans of 3 tennis balls each
   is 6 tennis balls. 5 + 6 = 11.
   The answer is 11.
  • PaLM 540B 在 GSM8K 數學題：17.9 → 56.9 2
  • 約 100B 參數以上才有效；小模型會寫出流暢但不合邏輯的推理 3

概念 · Yao et al. 2022

第二步：邊想邊做（ReAct）

讓模型交錯產生想法和行動：想法用來擬定、調整計畫，行動去外部取得資訊，觀察結果再回饋給下一步 1。

  • Thought：拆解目標、從觀察中抽重點、處理例外 2
  • Action：查 Wikipedia 只有三個動作 search、lookup、finish 3
  • Observation：外部回傳的結果，成為下一個 Thought 的依據 1

比較 · ReAct 論文的同一組實驗

只想、只做、邊想邊做：誰比較好？

CoT（只想）Act（只做）ReAct（邊想邊做）
查外部資料 1✗ 只用內部知識✓✓
寫出推理 2✓✗✓
HotpotQA 主要失敗原因 3幻覺 56%–推理錯誤 47%
  • 查外部資料能減少幻覺：HotpotQA 的失敗案例中 ReAct 幻覺 0%，CoT 56% 3
  • 沒有一種方法全面勝出：HotpotQA 上 CoT 略好，FEVER 上 ReAct 較好 4
  • 失敗方式互補，所以作者把 ReAct 和 CoT-SC 結合，兩個任務都拿到最佳成績 5

例子 · Schick et al. 2023

第三步：學會用工具（Toolformer）

模型自己學會在句子裡插入 API 呼叫：計算機、問答系統、Wikipedia 搜尋、翻譯、日曆 1。

Out of 1400 participants, 400 (or [Calculator(400 / 1400) → 0.29] 29%) passed the test.
  • 只保留「讓模型更好預測下文」的呼叫 2，再用這些資料 finetune 2
  • 數學題 ASDiv：Toolformer 40.4，約大 25 倍的 GPT-3 只有 14.0 3,4
  • 限制：每個輸入最多呼叫一次 5，不能串接工具，也不能改寫查詢 6

概念 · Shinn et al. 2023

第四步：從失敗中學習（Reflexion）

失敗後用文字反省「哪裡做錯、下次怎麼做」，存進記憶再試一次——不用更新模型權重 1。

  • Actor 行動 → Evaluator 打分數 → Self-Reflection 寫反省 2
  • ALFWorld 134 個環境完成 130 個 3
  • 寫程式 HumanEval：91.0（GPT-4 為 80.1）4
  • 小模型反省不起來：starchat-beta 0.26 → 0.26 5

概念 · Generative Agents（Park et al. 2023）

第五步：記憶、反思與計畫

LLM 打造的 25 個虛擬居民住在小鎮 Smallville 1。

  • 記憶流：用自然語言記下所有經歷 2
  • 挑記憶：三個分數加權排序（見右圖） 2
  • 反思：把大量觀察歸納成高層推論 3
  • 計畫：沒有計畫時，Klaus 會在 12 點、12 點半、1 點各吃一次午餐 4
⚠ 這裡的「反思」是歸納，不是針對失敗的反省 3

例子 · Generative Agents 的小鎮模擬

25 個 agent 的小鎮發生了什麼？

  • 兩個遊戲日的模擬中，知道情人節派對的 agent 從 1 個（4%）增加到 13 個（52%），全程沒有使用者介入 1
  • 被邀請的 12 個 agent 中，有 5 個準時出現 1
  • 100 位受試者評比回答「像不像真人」（TrueSkill）：完整架構 29.89；沒有記憶、反思、計畫只有 21.21 2,3
  • 但會加油添醋：把鄰居 Adam Smith 說成寫《國富論》的人 4

挑戰

Agent 還沒解決的問題

  • 幻覺：agent 也會很有自信地產生錯誤資訊，例如寫出錯誤的程式 1
  • 效率：每個動作可能要呼叫 LLM 好幾次，推論速度慢 1；模擬 25 個 agent 兩天就花了數千美元 2
  • Prompt 穩健性：各模組的 prompt 互相影響，換模型又要重調 1
  • 需要夠強的模型：小模型用 Reflexion 沒有進步 3
  • 角色扮演：網路上少見或新出現的角色，LLM 演不好 1

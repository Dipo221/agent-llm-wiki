- Toolformer 讓語言模型自己教自己在文字中插入 API 呼叫（計算機、問答系統、Wikipedia 搜尋、翻譯、日曆），只需要每個 API 幾個示範 [@schick2023-toolformer, Abstract]。
- 範例：Out of 1400 participants, 400 (or [Calculator(400 / 1400) → 0.29] 29%) passed the test.（Figure 1）[@schick2023-toolformer, §2]。
- 篩選：比較「給模型看呼叫＋結果」和「不呼叫」兩種情況下後面 token 的 loss，只保留讓 loss 降低的呼叫 [@schick2023-toolformer, §2]。
- ASDiv（數學）：Toolformer 40.4，GPT-3 14.0，主要用計算機（97.9% 的例子）[@schick2023-toolformer, Table 4]。
- Toolformer 以 GPT-J 為基底，比較對象 GPT-3 約大 25 倍 [@schick2023-toolformer, §4.1]。
- 限制：不能串接工具，也不能互動式使用工具（例如瀏覽多筆搜尋結果或改寫查詢）[@schick2023-toolformer, §7]。

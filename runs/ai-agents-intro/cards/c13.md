- CoT 主要貢獻在 Planning（沒有回饋，single-path）：範例裡寫出推理步驟 [@wang2023-agent-survey, §2.1.3]、[@wei2022-chain-of-thought, §1]。
- ReAct 主要貢獻在 Planning（環境回饋）＋ Action：Thought → Action → Observation 迴圈 [@wang2023-agent-survey, §2.1.3]、[@yao2022-react, §2]。
- Toolformer 主要貢獻在 Action（外部工具）：self-supervised 學會何時呼叫 API [@wang2023-agent-survey, §2.1.4]、[@schick2023-toolformer, §2]。
- Reflexion 主要貢獻在 Planning（模型回饋）＋ Memory（hybrid）：失敗後寫文字反省，存進長期記憶 [@wang2023-agent-survey, §2.1.2]、[@shinn2023-reflexion, §3]。
- Generative Agents 主要貢獻在 Profile（手寫角色）＋ Memory（hybrid、反思）＋ Planning：記憶流、反思、日程計畫 [@wang2023-agent-survey, §2.1.1]、[@park2023-generative-agents, §4]。
- 依 arXiv 編號的時間順序：CoT（2201）→ ReAct（2210）→ Toolformer（2302）→ Reflexion（2303）→ Generative Agents（2304）→ Survey（2308）[@wei2022-chain-of-thought, p.1]、[@yao2022-react, p.1]、[@schick2023-toolformer, p.1]、[@shinn2023-reflexion, p.1]、[@park2023-generative-agents, p.1]、[@wang2023-agent-survey, p.1]。
- 後面的論文直接把前面的當零件：Reflexion 的 Actor 用 CoT 和 ReAct [@shinn2023-reflexion, §3]；ReAct 拿 CoT 當 baseline 並結合使用 [@yao2022-react, §3.2]。

- ReAct 讓 LLM 交錯產生「想法（Thought）」和「行動（Action）」：想法幫助擬定與調整計畫，行動去外部取得資訊，觀察結果再回饋給下一步推理 [@yao2022-react, Abstract]。
- CoT 是「靜態黑盒子」：只用模型內部知識推理，沒有接觸外部世界，所以會有 fact hallucination 和錯誤沿著推理累積的問題 [@yao2022-react, §1]。
- 一段軌跡的格式是 Thought → Action → Observation → Thought → …；Thought 的用途包括拆解目標、擬定計畫、從觀察中抽取重點、處理例外並調整計畫 [@yao2022-react, §2]。
- Wikipedia API 只有三個動作：search[entity]、lookup[string]、finish[answer] [@yao2022-react, §3.1]。
- ALFWorld：最佳 ReAct 成功率 71%，最佳 Act 45%，BUTLER（模仿學習）37% [@yao2022-react, §4]。
- 常見錯誤是重複產生之前的想法和動作，跳不出迴圈 [@yao2022-react, §3.3]。

- autonomous agent 是位於環境之中、感知環境並對其行動的系統，長期追求自己的目標，並影響自己之後感知到的東西 [@wang2023-agent-survey, §1]。
- 過去的 agent 多半依賴簡單的策略，在封閉受限的環境中學習，和人類學習方式差很多，很難做出像人的決策 [@wang2023-agent-survey, Abstract]。
- 和強化學習的 agent 相比，LLM-based agent 有更完整的世界知識，沒有針對特定領域訓練也能行動，而且提供自然語言介面、更好解釋 [@wang2023-agent-survey, §1]。
- 統一架構有四個模組：Profile 決定 agent 的角色、Memory 記住過去的行為與觀察、Planning 把複雜任務拆成子任務、Action 把決策轉成具體輸出 [@wang2023-agent-survey, §2.1]。
- Profile 影響 Memory 和 Planning，三者一起影響 Action [@wang2023-agent-survey, §2.1]。

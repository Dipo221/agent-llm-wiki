- Agent 失敗後用文字反省「哪裡做錯、下次怎麼做」，把反省存進記憶，下一次嘗試時帶著這些經驗重來；不更新模型權重 [@shinn2023-reflexion, Abstract]。
- 三個模組：Actor 產生文字與行動（可以是 CoT 或 ReAct）；Evaluator 替軌跡打分數；Self-Reflection 讀軌跡＋分數＋過去記憶，寫出具體的文字反省 [@shinn2023-reflexion, §3]。
- 流程：嘗試 → 評分 → 反省 → 把反省加進記憶 → 再嘗試，直到 Evaluator 判定通過或達到最大嘗試次數 [@shinn2023-reflexion, §3]。
- ALFWorld（134 個環境）：ReAct + Reflexion 完成 130 個 [@shinn2023-reflexion, §4.1]。
- HumanEval Python：Reflexion pass@1 91.0（GPT-4 為 80.1）[@shinn2023-reflexion, Table 1]。
- 自我修正是較強、較大模型才有的湧現能力：小模型 starchat-beta 用 Reflexion 沒有進步（0.26 → 0.26）[@shinn2023-reflexion, Table 4]。

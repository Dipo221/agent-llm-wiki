- 會不會查外部資料：CoT 不會，只用模型內部知識；Act 和 ReAct 會 [@yao2022-react, §1]。
- 會不會寫推理：CoT 會、Act 不會、ReAct 會 [@yao2022-react, §3.2]。
- HotpotQA 的主要失敗原因：CoT 是 Hallucination 56%，ReAct 是 Reasoning error 47% [@yao2022-react, Table 2]。
- 沒有一種方法全面勝出：HotpotQA 上 CoT 略好，FEVER 上 ReAct 較好 [@yao2022-react, §3.3]。
- 失敗方式互補，所以作者把兩者結合，HotpotQA 最佳 35.1（ReAct → CoT-SC），FEVER 最佳 64.6（CoT-SC → ReAct）[@yao2022-react, Table 1]。

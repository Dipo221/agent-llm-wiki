## 問題
# 只會聊天的 LLM，哪裡不夠？
大模型很會做新任務，卻在**算術、查事實**這類基本功能上表現差 [@schick2023-toolformer, Abstract]。
- **不會精確計算**、**不知道現在是什麼時間** [@schick2023-toolformer, §1]
- **拿不到最新資訊**，而且**容易幻覺**（hallucination）[@schick2023-toolformer, §1]
- ReAct 的作者把只靠內部知識推理的做法（例如 CoT）形容成「靜態黑盒子」：不接觸外部世界，錯誤會沿著推理累積 [@yao2022-react, §1]
> 💡 後面的 ReAct 要補的正是這種能力：**去外部取得資訊、觀察結果，再回饋給下一步** [@yao2022-react, Abstract]。

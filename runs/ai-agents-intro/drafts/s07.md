## 例子 · Schick et al. 2023
# 第三步：學會用工具（Toolformer）
模型**自己學會**在句子裡插入 API 呼叫：計算機、問答系統、Wikipedia 搜尋、翻譯、日曆 [@schick2023-toolformer, Abstract]。
```
Out of 1400 participants, 400 (or [Calculator(400 / 1400) → 0.29] 29%) passed the test.
```
- 只保留「讓模型更好預測下文」的呼叫 [@schick2023-toolformer, §2]，再用這些資料 finetune [@schick2023-toolformer, §2]
- 數學題 ASDiv：Toolformer **40.4**，約大 25 倍的 GPT-3 只有 **14.0** [@schick2023-toolformer, Table 4]、[@schick2023-toolformer, §4.1]
- 限制：每個輸入最多呼叫一次 [@schick2023-toolformer, §4.2]，不能串接工具，也不能改寫查詢 [@schick2023-toolformer, §7]

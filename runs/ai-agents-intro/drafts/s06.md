## 比較 · ReAct 論文的同一組實驗
# 只想、只做、邊想邊做：誰比較好？
| | CoT（只想） | Act（只做） | ReAct（邊想邊做） |
|---|---|---|---|
| 查外部資料 [@yao2022-react, §1] | ✗ 只用內部知識 | ✓ | ✓ |
| 寫出推理 [@yao2022-react, §3.2] | ✓ | ✗ | ✓ |
| HotpotQA 主要失敗原因 [@yao2022-react, Table 2] | 幻覺 56% | – | 推理錯誤 47% |
- 查外部資料能減少幻覺：HotpotQA 的失敗案例中 ReAct 幻覺 **0%**，CoT **56%** [@yao2022-react, Table 2]
- 沒有一種方法全面勝出：HotpotQA 上 CoT 略好，FEVER 上 ReAct 較好 [@yao2022-react, §3.3]
- 失敗方式互補，所以作者把 ReAct 和 CoT-SC 結合，兩個任務都拿到最佳成績 [@yao2022-react, Table 1]

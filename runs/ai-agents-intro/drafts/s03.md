## 概念
# Agent 的定義與四塊積木
**Agent** 是位於環境之中、感知環境並對其行動的系統，長期追求自己的目標 [@wang2023-agent-survey, §1]。
- **Profile**：決定 agent 的角色
- **Memory**：記住過去的行為與觀察
- **Planning**：把複雜任務拆成子任務
- **Action**：把決策轉成具體輸出 [@wang2023-agent-survey, §2.1]
> 💡 Profile 影響 Memory 和 Planning，三者一起影響 Action [@wang2023-agent-survey, §2.1]。

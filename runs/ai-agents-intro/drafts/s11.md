## 比較 · 用 Survey 的四模組整理
# 把五篇論文放回四塊積木
| 論文 | 主要補強的模組 | 做法 |
|---|---|---|
| CoT | Planning（無回饋）[@wang2023-agent-survey, §2.1.3] | 範例寫出推理步驟 [@wei2022-chain-of-thought, §1] |
| ReAct | Planning（環境回饋）＋Action [@wang2023-agent-survey, §2.1.3] | Thought→Action→Observation [@yao2022-react, §2] |
| Toolformer | Action（工具）[@wang2023-agent-survey, §2.1.4] | 自己學會何時呼叫 API [@schick2023-toolformer, §2] |
| Reflexion | Planning（模型回饋）＋Memory [@wang2023-agent-survey, §2.1.2] | 失敗後寫反省存進記憶 [@shinn2023-reflexion, §3] |
| Generative Agents | Profile＋Memory＋Planning [@wang2023-agent-survey, §2.1.1]、[@wang2023-agent-survey, §2.1.2] | 記憶流、反思、日程計畫 [@park2023-generative-agents, §4] |
- 後面的論文把前面的當**零件**：Reflexion 的 Actor 用 CoT 和 ReAct [@shinn2023-reflexion, §3]
> ※「想 → 做 → 工具 → 反省 → 記憶」是本簡報的整理順序，不是論文的結論。

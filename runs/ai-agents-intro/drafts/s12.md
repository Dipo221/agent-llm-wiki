## 挑戰
# Agent 還沒解決的問題
- **幻覺**：agent 也會很有自信地產生錯誤資訊，例如寫出錯誤的程式 [@wang2023-agent-survey, §6]
- **效率**：每個動作可能要呼叫 LLM 好幾次，推論速度慢 [@wang2023-agent-survey, §6]；模擬 25 個 agent 兩天就花了數千美元 [@park2023-generative-agents, §8.2]
- **Prompt 穩健性**：各模組的 prompt 互相影響，換模型又要重調 [@wang2023-agent-survey, §6]
- **需要夠強的模型**：小模型用 Reflexion 沒有進步 [@shinn2023-reflexion, Table 4]
- **角色扮演**：網路上少見或新出現的角色，LLM 演不好 [@wang2023-agent-survey, §6]

# N3 大綱：AI Agents 是什麼？

> 讀者：用過 ChatGPT、沒讀過論文的大學生。看完要能回答：agent 跟聊天機器人差在哪？agent 由哪幾塊組成？五篇經典論文各補了哪一塊？
> 教學順序：先丟問題 → 給定義和地圖 → 依時間一塊一塊補上（想 → 做 → 工具 → 反省 → 記憶）→ 放回地圖 → 挑戰 → 小結。
> 「想 → 做 → 工具 → 反省 → 記憶」是我們整理的教學順序，不是論文的結論（見 wiki agent-framework-map 的 💭 筆記），簡報上會說明這一點。

## S01 AI Agents 是什麼？從「會聊天」到「會做事」
- 角色：封面
- 目標：知道今天要講什麼、資料來自哪 6 篇論文
- 卡片：c13

## S02 只會聊天的 LLM，哪裡不夠？
- 角色：問題
- 目標：知道 LLM 的先天限制（不會精確計算、拿不到新資訊、會幻覺），引出「需要會行動的 agent」
- 卡片：c03, c05

## S03 Agent 的定義與四塊積木
- 角色：概念
- 目標：記住 agent 的定義，以及 Profile／Memory／Planning／Action 四個模組各做什麼
- 卡片：c01

## S04 第一步：先想再答（Chain-of-Thought）
- 角色：例子
- 目標：看懂 CoT 範例，知道它讓 GSM8K 從 17.9 提升到 56.9，但只在大模型有效
- 卡片：c04

## S05 第二步：邊想邊做（ReAct）
- 角色：概念
- 目標：看懂 Thought → Action → Observation 迴圈，知道 ReAct 能查外部資料
- 卡片：c05

## S06 只想、只做、邊想邊做：誰比較好？
- 角色：比較
- 目標：知道 CoT 容易幻覺、ReAct 容易卡住，兩者互補、結合最好
- 卡片：c06, c07

## S07 第三步：學會用工具（Toolformer）
- 角色：例子
- 目標：看懂「在句子裡插入計算機呼叫」的例子，知道小模型＋工具能贏大模型
- 卡片：c08, c07

## S08 第四步：從失敗中學習（Reflexion）
- 角色：概念
- 目標：看懂「嘗試 → 評分 → 反省 → 再試」，知道它不用重新訓練模型
- 卡片：c09

## S09 第五步：記憶、反思與計畫（Generative Agents）
- 角色：概念
- 目標：知道記憶流怎麼挑出要用的記憶（recency／importance／relevance），以及為什麼需要計畫
- 卡片：c10, c12, c15

## S10 25 個 agent 的小鎮發生了什麼？
- 角色：例子
- 目標：知道 agent 能自己傳播派對消息、準時赴約，也會加油添醋
- 卡片：c11

## S11 把五篇論文放回四塊積木
- 角色：比較
- 目標：能把每篇論文對應到它補強的模組，並看到「後面的論文把前面的當零件」
- 卡片：c13, c14

## S12 Agent 還沒解決的問題
- 角色：概念
- 目標：知道幻覺、效率、prompt 穩健性等挑戰，以及各論文自己承認的限制
- 卡片：c02, c09, c11

## S13 小結：一句話記住 AI Agent
- 角色：小結
- 目標：能用四塊積木（Profile、Memory、Planning、Action）說出 agent 和聊天機器人的差別，並回想五篇論文各補哪一塊
- 卡片：c01, c13
